# Arrakis 1984 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Finalize the approved 1984 backgrounds as independent, tested packages.

**Architecture:** Each package owns canonical sources and produces three standalone
runtime distributions. The root catalog and CI discover the packages but supply
no runtime, build, or test dependencies.

**Tech Stack:** JavaScript, WebGL/GLSL, native custom elements, SVG/CSS, Node tests,
esbuild 0.28.2, Playwright 1.63.0, pngjs 7.0.0, sharp 0.35.5.

**Spec:** [Approved design](../specs/2026-10-25-arrakis-1984-design.md).

## Global constraints

- Names are `arrakis-desert-1984` and `arrakis-orbit-1984`.
- Node.js 22 or newer; no runtime dependencies or CDN requests.
- Preserve the approved artwork and motion settings recorded in the spec.
- Every runtime variant folder works when copied alone.
- Each package has its own build scripts, lockfile, tests, README, and credits.
- Original `arrakis-desert/` and `arrakis-orbit/` stay unchanged.
- No obsolete look selector or preview controls inside standalone variants.
- Do not commit, push, or alter another task's files from a package worker.

## Review focus

1. Nested component URLs must resolve textures and fallback without parent files.
2. Async loading followed by disconnection must not leak resources or render.
3. Reduced motion must stop SVG animation through the host's still-file selection.
4. SVG outputs must preserve the approved moon placement and full-height storm.
5. Freshness checks must fail on missing outputs or changed canonical inputs.
